# wclay24 Public Notices

Public privacy policies, terms, disclosures, data-use notices, and support information for applications and projects maintained by wclay24.

## GitHub Pages setup

1. Create a public repository named:

   `wclay24-public-notices`

2. Upload all files from this package.

3. In GitHub, open:

   **Settings → Pages**

4. Under **Build and deployment**, choose:

   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`

5. Save.

Your site should publish at approximately:

`https://wclay24.github.io/wclay24-public-notices/`

Update the contact email and effective dates before using these notices publicly if you want a different public contact point.

These notices are written for transparency and operational use. They are not legal advice and should be reviewed if the application scope, data practices, or external integrations materially change.
